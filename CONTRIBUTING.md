Thank you for your interest in contributing to K9Hope!

- **Website:** [k9hope.in](https://k9hope.in)
- **Repository:** [github.com/Rvunveil/k9hope-canine-blood-donation](https://github.com/Rvunveil/k9hope-canine-blood-donation)
- **Issues:** [github.com/Rvunveil/k9hope-canine-blood-donation/issues](https://github.com/Rvunveil/k9hope-canine-blood-donation/issues)

## 🚀 Getting Started

1. Fork the repo: [github.com/Rvunveil/k9hope-canine-blood-donation](https://github.com/Rvunveil/k9hope-canine-blood-donation)
2. Clone your fork: `git clone https://github.com/YOUR-USERNAME/k9hope-canine-blood-donation.git`
3. Create a branch: `git checkout -b feature/your-feature`
4. Make changes and commit
5. Push and create a Pull Request

## 🛠 Development

1. Install dependencies:
   ```bash
   npm install
   ```

2. Set up environment variables:
   Copy `env.template` to `.env.local` and fill in the values.

3. Run the development server:
   ```bash
   npm run dev
   ```

## 🤝 Code of Conduct

Please note that this project is released with a Contributor Code of Conduct. By participating in this project you agree to abide by its terms.
