# Security policy

K9HOPE handles information about dogs, their owners and veterinary clinics. Please report security problems privately so they can be fixed before they are disclosed.

## How to report

- Use GitHub's **Report a vulnerability** button on the repository's Security tab (private vulnerability reporting must be enabled by a maintainer under Settings → Code security).
- Please do **not** open a public issue for a security problem.

Include what you found, how to reproduce it, and what data could be affected. We aim to acknowledge reports within 7 days.

## Scope

In scope: this repository's application code, Firebase security rules and API routes.
Out of scope: third-party services (Firebase, Vercel, Google AI, Uploadcare) themselves.

## Handling data

Never include real donor, patient or owner information in reports, screenshots or test data.
